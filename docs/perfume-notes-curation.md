# Curaduria de notas olfativas

Objetivo: mejorar busqueda, filtros y autoridad comercial del catalogo sin inventar notas.

## Metodo

- Prioridad 1: pagina oficial de la marca o casa perfumera.
- Prioridad 2: Fragrantica, Sephora o retailer con piramide clara cuando la marca solo publica acordes generales.
- Prioridad 3: mantener el dato existente si coincide razonablemente y no hay una fuente mejor.
- Las notas se guardan en espanol sin acentos para mantener consistencia con el dataset actual.
- Los nombres publicos de Empire Essence se mantienen. La inspiracion se usa solo para alinear familia, notas y busqueda.
