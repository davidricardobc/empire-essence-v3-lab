## Hallazgos

1. Wompi esta activo en `.env.local`.

   El checkout local entra por flujo Wompi porque existen `NEXT_PUBLIC_WOMPI_PUBLIC_KEY` y `WOMPI_INTEGRITY_SECRET`.
   Antes de publicar, validar si esas credenciales son sandbox o produccion.

2. Typecheck puede fallar si el servidor dev corrompe `.next/dev/types`.

   Solucion operativa: detener `next dev` y limpiar `.next/dev` antes de correr `npm run typecheck`.

3. No hay Playwright instalado localmente.

   La auditoria visual automatizada queda pendiente. Para QA visual completo conviene agregar una configuracion minima de Playwright en un commit separado.

4. WhatsApp y Wompi conviven bien, pero la decision comercial debe definirse.

   Si Wompi no esta aprobado para uso real, dejar variables vacias en produccion y operar solo por WhatsApp.
